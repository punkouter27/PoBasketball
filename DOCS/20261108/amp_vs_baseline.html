Walking policy: original RL vs AMP

Both started from the same checkpoint (l1_v2_armstop) and trained for 90 minutes on the same environment, pushes and speed commands. The original run adds hand-written arm penalties; the AMP run instead learns style from 22 minutes of LocoMuJoCo motion capture (MimicKit's Adversarial Motion Priors).

Original RL (hand-tuned reward)AMP (motion-capture style)

TL;DR Task: the original RL scores higher (97 % original vs 97 % AMP, gate 90 %). Style: the original RL moves more like the motion capture (human-likeness 0 vs 0; 100 = indistinguishable).
